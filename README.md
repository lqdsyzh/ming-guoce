# 天命·国策 — 大明王朝国策模拟游戏

> 18步年度推演，六大创意系统，7大板块社区。你将扮演大明帝王，运筹帷幄，决胜千里。

## 游戏简介

天命·国策是一款以大明王朝为背景的国策模拟经营游戏。你将扮演大明帝王，在18步年度推演中权衡国策、调配文武、征伐四方、祭祀天地——人口、粮产、商业、国库、军备、稳定、天命，一环扣一环，牵一发而动全身。

## 核心特色

| 维度 | 数值 | 说明 |
|------|------|------|
| 年度推演 | 18步 | 每一步决策影响全局 |
| 创意系统 | 6大 | 内廷/钦天监/锦衣卫/龙椅排行榜/共治投票/云存档 |
| 社区板块 | 7个 | 综合讨论/攻略/王朝风云/战绩晒图/闲聊/站务/精选 |
| 王朝可能 | 无限 | 每次开局都是全新的国运 |

## 六大创意系统

- **🏮 内廷风云** — 后宫选秀、皇子分封、宦官司礼监、藩王靖难
- **🔭 钦天监·灾异祥瑞** — 荧惑守心、黄河决口、麒麟现世、五星连珠
- **🛡 锦衣卫·细作PvP** — 玩家间派细作渗透、离间煽动、反间抓捕
- **🏆 龙椅排行榜** — 王朝终章写入史册，多维度排名
- **🗳 共治投票** — 社区发起国策投票，民主决策王朝走向
- **☁ 云端存档** — 游戏进度云端保存，跨设备读取

## 技术架构

| 层 | 技术 | 说明 |
|----|------|------|
| 后端 | Node.js 内置模块 | 零外部依赖，http + crypto + node:sqlite |
| 数据库 | SQLite | 15+表，用户/社区/游戏存档/通知/投票 |
| 前端 | 原生 HTML/CSS/JS | 零框架依赖，单页应用 |
| 部署 | Railway / Render / Docker | 多平台一键部署 |

## 快速开始

```bash
# 需要 Node.js >= 22（支持 node:sqlite）
cd tianming
node server.js

# 访问 http://localhost:3000
# 管理后台 http://localhost:3000/admin.html
# 管理员账号: admin / admin123
```

## 项目结构

```
tianming/
├── server.js          # 后端服务（零依赖，Node内置模块）
├── data.db            # SQLite 数据库
├── public/
│   ├── index.html     # 主应用（游戏+社区+个人主页）
│   ├── admin.html     # 管理后台
│   ├── promo.html     # 宣传落地页
│   ├── game.js        # 游戏逻辑
│   ├── app.js         # 前端应用逻辑
│   └── style.css      # 样式
├── Dockerfile         # Docker 部署
├── railway.json       # Railway 部署
├── render.yaml        # Render 部署
└── deploy-aliyun.sh   # 阿里云部署脚本
```
